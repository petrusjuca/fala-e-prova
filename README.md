# Fala e Prova

Tutorial de **[@petrusjuca](https://www.instagram.com/petrusjuca/)** para montar Reels e TikToks com a fala real de um político e, logo em seguida, o que a desmente — com fonte e data em cada corte — usando o Claude Code.

**Página:** https://petrusjuca.github.io/fala-e-prova/

O que tem na página:
- passo a passo, da instalação à conferência final;
- pedidos prontos para colar no Claude;
- o `CLAUDE.md` com as regras do método (nada inventado, só fala real, fonte em tudo);
- checklist do que conferir antes de postar.

Quer aprender a fazer? Me chama no direct: [@petrusjuca](https://www.instagram.com/petrusjuca/).
